# AlphaFold 3 modelling of TF–TF–DNA complexes on high- vs low-syntax composite motifs

AlphaFold 3 (AlphaFast) structures of full-length transcription-factor (TF) pairs bound
to double-stranded DNA carrying composite motifs that tangermeme scores as **high**
or **low** "hard syntax" (n = 100 backgrounds per class, ρ ≥ 0.6). The models are
compared on protein–protein and protein–DNA buried surface area, contacts, ipTM and
PAE. A RUNX1–ETS1 positive control is benchmarked against the crystal structure
4L0Z (Shrivastava et al., 2014).

## Data flow

```
data/*.csv ──► af3_screen_n100_rho0.6/  (MSA → 6,400 AF3 models)
                   │
                   └─► outputs_inference/ ──► notebooks/0–6 ──► results/{tables,figures}
data/pdb/4L0Z ──────────────────────────────► notebooks/6
af3_screen…/outputs_msa ──► af3_control_runx1_ets1_4L0Z/  (reuses the RUNX1_ETS1 MSA)
```

Model files are named `<TF1>_<TF2>_<motif1>_<motif2>_<high|low>_bg<idx>`; for example,
`RUNX1_ETS1_14_64_high_bg81`. Chains are A = TF1, B = TF2, C = motif strand and
D = reverse complement.

## Reproducing

1. **Structures (HPC):** set `SIF`, `WEIGHTS_DIR`, `DB_DIR` and the SLURM account in
   `af3_screen_n100_rho0.6/config.sh`, then run `./submit_all.sh` from that folder.
   Every stage skips finished work. `inputs_inference/` was deleted after the run;
   `sbatch scripts/03_build_inference.sbatch` regenerates it from `outputs_msa/` + `data/`
   (each job's exact input is also kept as `outputs_inference/<name>_data.json`).
2. **Analysis:** start Jupyter in `notebooks/` and run notebooks 0 → 6 in order.
   Notebooks 2, 4 and 6 read tables written by earlier ones. Notebooks 4 and 7 first need
   `python scripts/fetch_tf_domains.py` and `sbatch scripts/domain_bsa.sbatch` (from the project root). Notebooks 4 to 6 need PyMOL.
   All paths are relative to `notebooks/`.

`REORG_MANIFEST.tsv` records every file move made when the project was consolidated
on 2026-11-04 (old path → new path). Afterwards `archive/pilot_analyses/` (51 GB of
July–Aug 2026 pilots) and `af3_screen_n100_rho0.6/inputs_inference/` were deleted.

## Version control

Git tracks the code, notebooks, input tables, result tables and PDF figures (about 25 MB). The AF3
inputs/outputs, `results/cache/`, `archive/`, logs, rendered PNG/MP4 panels and notebook 5 (69 MB of
embedded output) stay on RDS only; see `.gitignore`.
